# Stilltone

Stilltone is a private AI meeting-notes app for Mac. It records calls without a bot, transcribes and summarizes them
on your Mac, and keeps a memory across meetings: decisions, action items and what changed since last time.

- **No bot in your calls.** It records system audio and your microphone, so it works with any call app.
- **On your Mac.** Transcription, summaries and memory run on-device. Your meetings are plain Markdown and JSON files.
- **Memory across meetings.** Each new meeting updates a running record: later decisions replace earlier ones, and
  action items carry forward until they're done, each linked to the moment it was said.
- **Works with your tools.** Obsidian export and a local MCP server for Claude, Cursor and other AI apps.
